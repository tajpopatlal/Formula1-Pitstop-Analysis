# Formula 1 Pit Stop Analysis

## Overview

This project investigates whether there is a statistically significant difference in average pit-stop times between Mercedes and Alpine Formula One teams.

The analysis applies statistical inference techniques and confidence intervals to compare team performance.

## Methods

- Exploratory Data Analysis
- Histograms
- QQ Plots
- Confidence Intervals
- Statistical Inference

## Skills Demonstrated

- R Programming
- Statistical Inference
- Hypothesis Testing
- Data Visualisation
